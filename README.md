### Hi, I'm Vijay Velpula 👋

**Lead Data Scientist · Marketing Measurement · Hyderabad, India**

I build models that answer one question for marketers: *what actually worked?*
My work sits where Bayesian statistics meets marketing spend: marketing mix modeling, incrementality testing and causal inference for enterprise clients.

- 📊 **Bayesian Marketing Mix Modeling:** adstock (geometric / Weibull), saturation curves, priors, parameter recovery, convergence diagnostics (R-hat, ESS)
- 🧪 **Incrementality & experimentation:** geo-holdout tests, difference-in-differences, synthetic control, CUPED
- 🔗 **Causal inference:** turning observational marketing data into decisions you can defend to a CFO
- 🤖 **Applied AI:** LLM agents and pipelines with LangGraph and LiteLLM

10+ years across software engineering and data science, with the last several focused on measurement: identity resolution and multi-touch attribution, then MMM and experimentation.
